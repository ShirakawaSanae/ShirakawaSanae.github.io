# Academic Homepage

A GitHub Pages-compatible personal academic website built with the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) remote theme.

The key places to customize are:

- `index.md` for your biography and research interests.
- `_data/publications.yml` for publications.
- `_data/projects.yml` for projects.
- `_data/friends.yml` for friend links.
- `_posts/` for public blog posts.
- `_config.yml` for your name, photo, contact details, and GitHub repository settings.

See [CONTENT_GUIDE.md](CONTENT_GUIDE.md) for local preview, publication rules, and GitHub Pages setup.

Moving from Windows to a Mac? See [MACOS_TRANSFER.md](MACOS_TRANSFER.md) for the one-time local setup and transfer checklist.
